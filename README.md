# Roblox Scripting Portfolio

A minimalist, responsive portfolio built for GitHub Pages using plain HTML, CSS, and JavaScript.

## Customize it

Open `index.html` and replace:

- `YOUR-USERNAME`
- `YOUR-GAME-ID`
- `YOUR-ASSET-ID`
- `YOUR-EMAIL@example.com`
- `YOUR_DISCORD_USERNAME`
- The project descriptions and links

Change the accent color in `style.css`:

```css
--accent: #8bffb0;
```

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)` folder.
7. Save.

For a personal root site, name the repository:

```text
YOUR-USERNAME.github.io
```

Otherwise, the site will normally appear at:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```
